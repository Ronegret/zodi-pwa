## 🧭 Overview
ZODI is an AI-powered astrology product — horoscope, tarot, natal charts and numerology — delivered as a cross-platform app (web + Android) with a freemium model.

## ✨ Features
- AI-generated readings: horoscope, tarot, natal chart, numerology
- Freemium plans
- Web + Android (Capacitor) from one codebase
- Firebase backend & auth

## 🛠️ Built with
`Next.js` · `TypeScript` · `Capacitor` · `Firebase` · `AI / LLM`

## 🚀 Run locally
```bash
npm install
cp .env.example .env.local   # add your keys
npm run dev
```
