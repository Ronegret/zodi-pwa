# ZODI — AI Astral Oracle (App)

ZODI is an AI-powered astrology product: horoscope, tarot, natal charts and
numerology, with a freemium model. Built as a cross-platform app (web + mobile).

🔗 **Case study:** [rodrigonegrete.es/zodi](https://www.rodrigonegrete.es/zodi/)

## ✨ Features
- AI-generated readings: horoscope, tarot, natal chart, numerology
- Freemium plans
- Web + Android (Capacitor) from one codebase
- Firebase backend

## 🛠️ Tech stack
`Next.js` · `TypeScript` · `Capacitor (Android)` · `Firebase` · `AI (LLM)`

## 🚀 Run locally
```bash
npm install
cp .env.example .env.local   # add your keys
npm run dev
```
